# grooming-check

Grooming Check Web App — replaces UFicon's Google Form (UFicon-CHK-001) daily store grooming inspection with a proper approval workflow.

- **Store Inspector**: creates a daily inspection, checks all 14 grooming items (pass requires a photo, fail requires a note), submits for HR review.
- **HR Reviewer**: reviews submitted inspections, approves or rejects (with a mandatory reason) — rejected inspections go back to the inspector for correction and resubmission, looping until approved.

No login in this MVP (per the requirement doc's explicit MVP decision) — free-text name entry only. See the doc's "Open Questions" section for what should be confirmed before a v2.
